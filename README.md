# Flappy Bird With Database (Locally Hosted)

A Python game inspired by the classic Flappy Bird, developed using Pygame with persistent player data stored in a locally hosted MySQL database.

This project explores multiple aspects of game development, including:

- Object-Oriented Programming (OOP)
- Real-time game development with Pygame
- Collision detection and gravity-based movement mechanics
- Dynamic difficulty scaling through increasing levels and obstacle speed
- Player score tracking and statistics
- MySQL database integration for persistent player data

To run the project with database support, install **XAMPP** from [https://www.apachefriends.org/](https://www.apachefriends.org/), then start the **Apache** and **MySQL** services before launching the game.

The goal is to recreate the classic Flappy Bird gameplay while demonstrating game development principles, object-oriented programming, and database integration in Python.
