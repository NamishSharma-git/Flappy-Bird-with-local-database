Flappy Bird

A Python game inspired by Flappy Bird, developed using Pygame with persistent player data stored in a MySQL database.

This project explores several core programming concepts, including:

Object-Oriented Programming (OOP) using classes for the player and obstacles
Real-time game development with Pygame
Collision detection and gravity-based movement mechanics
Dynamic difficulty scaling through increasing speed and levels
Player input validation and score tracking
MySQL database integration for storing player details, high scores, levels, and retries

The goal of the project is to recreate the classic Flappy Bird gameplay while demonstrating game development principles, database integration, and Python programming techniques in a complete desktop application.
